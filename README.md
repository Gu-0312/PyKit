## English

**PyKit** is a modern graphical tool for one-click packaging of Python projects into Windows executables, built with PySide6 and QFluentWidgets.

### Features

- **One-Click Packaging** — Turn Python scripts into standalone `.exe` files effortlessly
- **Dependency Auto-Detection** — Automatically scans and includes hidden imports
- **Module Exclusion** — Smart exclusion of test/docs/example modules to reduce size
- **UPX Compression** — Optional UPX compression for smaller executables
- **Inno Setup Installer** — Generate professional Windows installers
- **Batch Packaging** — Package multiple projects at once
- **Template Management** — Save, load, import, and export packaging configurations
- **Pack History** — Track all packaging operations with statistics
- **Environment Checker** — Verify Python, PyInstaller, and other dependencies
- **Icon Maker** — Convert images to `.ico` files for your executables
- **Virtual Environment Support** — Scan, detect, and create venvs from the GUI
- **Preset Configurations** — Default / Minimal Size / Fast Debug / Compatibility presets
- **Dark & Light Themes** — Automatic, dark, or light theme support
- **Bilingual UI** — Full Chinese and English language support

## 中文

**PyKit** 是一款基于 PySide6 和 QFluentWidgets 构建的现代化图形化工具，支持一键将 Python 项目打包为 Windows 可执行文件。

### 功能特性

- **一键打包** — 轻松将 Python 脚本转换为独立的 `.exe` 可执行文件
- **依赖自动检测** — 自动扫描并包含隐藏导入（Hidden Imports）
- **模块智能排除** — 自动排除测试/文档/示例模块，减小体积
- **UPX 压缩** — 可选 UPX 压缩，进一步减小可执行文件体积
- **Inno Setup 安装包** — 生成专业的 Windows 安装程序
- **批量打包** — 同时打包多个项目
- **模板管理** — 保存、加载、导入、导出打包配置
- **打包历史** — 记录所有打包操作及统计信息
- **环境检查** — 验证 Python、PyInstaller 等依赖是否就绪
- **图标制作** — 将图片转换为 `.ico` 图标文件
- **虚拟环境支持** — 在界面中扫描、检测、创建 venv
- **预置配置** — 默认 / 最小体积 / 快速调试 / 兼容模式四种预设
- **明暗主题** — 支持自动、深色、浅色三种主题模式
- **中英双语** — 完整的中文和英文界面支持
