# PyKit - Python EXE Packer

[项目地址 / Repository](python_exe_packer/README.md)

一键将 Python 项目打包为 Windows 可执行文件的图形化工具。  
A graphical tool for one-click packaging of Python projects into Windows executables.

```bash
cd python_exe_packer
pip install -r requirements.txt
python main.py
```
