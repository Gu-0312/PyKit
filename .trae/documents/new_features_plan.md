# 新增超级实用功能计划（第二批）

## 项目现状分析

当前项目是一个基于 PyInstaller 的 Python 一键打包工具，已实现的核心功能：
- 基础打包配置（源文件、输出目录、文件名）
- 打包模式切换（单文件/多文件）
- 自动依赖检测与排除
- 虚拟环境自动检测
- 模板管理（保存/加载/删除）
- 安装包生成（Inno Setup）
- UPX 压缩支持

## 新一批超级实用功能

### 功能 1：打包文件分析器

**功能描述**：分析生成的 EXE 或目录内部包含哪些模块及各模块占用空间，帮助用户精准瘦身。

**实用价值**：
- 直观了解打包产物的构成
- 精准定位体积过大的模块
- 指导用户添加排除模块来减小体积
- 支持导出分析报告

**实现方案**：
- 在打包完成后自动分析输出文件
- 使用 PyInstaller 的 `--debug=list` 参数获取模块列表
- 解析 PYZ 归档文件分析内部结构
- 显示模块大小排序表格

### 功能 2：打包前后钩子脚本

**功能描述**：支持配置在打包前/后自动执行自定义 Python 脚本或 Shell 命令。

**实用价值**：
- 打包前：自动备份、清理临时文件、修改配置等
- 打包后：自动签名、上传、通知等
- 实现自动化工作流

**实现方案**：
- 在高级选项中添加钩子脚本配置
- 支持 Python 脚本和 Shell 命令两种类型
- 支持配置脚本参数
- 执行结果记录到日志

### 功能 3：自动版本号递增

**功能描述**：每次打包后自动将版本号递增（支持自定义递增规则），并可写回配置文件。

**实用价值**：
- 避免手动修改版本号的繁琐
- 确保版本号不会重复
- 支持语义化版本规则（major.minor.patch）

**实现方案**：
- 在打包配置中添加版本递增选项
- 支持选择递增类型（major/minor/patch）
- 可选写回项目的 `_version.py` 或其他配置文件
- 支持自定义版本格式

### 功能 4：依赖树可视化

**功能描述**：以树状图展示项目依赖关系，直观发现冗余依赖。

**实用价值**：
- 清晰了解项目依赖结构
- 快速发现未使用的依赖
- 帮助优化依赖配置

**实现方案**：
- 使用 `pip show` 或 `importlib.metadata` 获取依赖树
- 使用 matplotlib 或 tkinter 绘制树状图
- 支持展开/折叠节点
- 显示依赖版本信息

### 功能 5：代码混淆集成

**功能描述**：打包前自动调用代码混淆工具（如 PyArmor）对源码进行混淆处理。

**实用价值**：
- 保护知识产权，防止代码被反编译
- 提升软件安全性
- 一键集成，无需额外操作

**实现方案**：
- 在高级选项中添加代码混淆开关
- 自动检测并安装 PyArmor
- 在打包前对源码进行混淆处理
- 支持自定义混淆参数

### 功能 6：配置导入导出

**功能描述**：将当前打包配置导出为 JSON 文件，支持从文件导入配置。

**实用价值**：
- 团队共享配置，确保一致的打包参数
- 配置文件纳入版本管理（Git）
- 快速迁移配置到其他机器
- 支持配置模板市场（可选扩展）

**实现方案**：
- 在模板管理中添加导入/导出功能
- 支持导出为标准 JSON 格式
- 支持导入并自动填充配置界面
- 支持配置文件版本校验

## 功能优先级建议

| 优先级 | 功能 | 理由 |
|--------|------|------|
| 高 | 打包文件分析器 | 帮助用户优化打包体积，最实用 |
| 高 | 配置导入导出 | 团队协作必备，提高工作效率 |
| 中 | 打包前后钩子脚本 | 自动化工作流，高级用户需求 |
| 中 | 自动版本号递增 | 提升打包流程自动化程度 |
| 低 | 依赖树可视化 | 已有第三方工具可用 |
| 低 | 代码混淆集成 | 需要额外依赖，适用场景有限 |

## 推荐实施方案

建议先实现 **优先级最高的 4 个功能**：

1. **打包文件分析器** - 核心实用功能，帮助优化体积
2. **配置导入导出** - 团队协作必备
3. **打包前后钩子脚本** - 自动化工作流
4. **自动版本号递增** - 提升自动化程度

## 风险与依赖

- **代码混淆集成**：需要额外安装 `pyarmor` 库
- **依赖树可视化**：需要额外安装 `matplotlib` 库（可选）
- **所有功能**：需要确保与现有代码结构兼容
